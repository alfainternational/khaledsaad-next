# نقل المنصة من next إلى الدومين الأساسي

1. جمّد تحرير الموقع القديم خلال نافذة النقل.
2. خذ نسخة احتياطية واختبر استعادتها في قاعدة منفصلة.
3. نفّذ الاستيراد النهائي للمحتوى المعتمد فقط.
4. اختبر خريطة كل URL قديم إلى URL جديد بحالة 301 أو 410 مقصودة.
5. خفّض DNS TTL قبل النقل بـ24 ساعة.
6. غيّر `APP_URL` و`PLATFORM_PUBLIC_HOST` إلى `https://khaledsaad.net`.
7. حدّث canonical وrobots وsitemap ثم امسح caches.
8. وجّه الدومين الأساسي إلى الإصدار الجديد، ووجّه `next` إليه بعد نافذة الاستقرار.
9. راقب أخطاء 404 و5xx، الفهرسة، webhooks والطوابير لمدة 72 ساعة.
10. عند rollback أعد الدومين للموقع القديم ووجّه المستخدمين المسجلين إلى `next` مع الحفاظ على قاعدة بيانات المنصة الجديدة دون كتابة مزدوجة.
